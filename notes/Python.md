# Python

**Summary**: Notes on Python packages and tools. Related: [[Agriculture]].
**Last updated**: 2026-11-18

---

- [End-to-End Google Earth Engine (Spatial Thoughts)](https://courses.spatialthoughts.com/end-to-end-gee.html): Full course on applied remote sensing in Earth Engine: basics, classification, change detection, apps and the Python API, with guided projects. Video lectures: [YouTube playlist](https://www.youtube.com/playlist?list=PLppGmFLhQ1HJuIb7qMiKIv11HiEQhy3ha). Main topic: [[Remote_Sensing]]. See also [[Google_Earth_Engine]]. *Keywords*: Google Earth Engine, course, classification, change detection, Python API
- [AI Python for Beginners (DeepLearning.AI)](https://learn.deeplearning.ai/courses/ai-python-for-beginners/lesson/2/what-is-computer-programming%3F): Beginner course teaching Python basics (data, variables, functions) while writing code alongside an AI chatbot. See [[Machine_Learning]]. *Keywords*: Python, beginners, AI assistant, course, programming basics
- [Introduction to GIS Programming (Qiusheng Wu)](https://geog-312.gishub.org/book/about/syllabus.html): Free course covering Python basics and geospatial libraries such as GeoPandas, Rasterio, Xarray and Leafmap. Also: [software overview](https://geog-312.gishub.org/book/software/overview.html), [YouTube lectures (Fall 2024)](https://www.youtube.com/playlist?list=PLAxJ4-o7ZoPfb18kNe2luWX9xKg1233i9). Main topic: [[GIS]]. *Keywords*: GIS programming, Python, GeoPandas, Leafmap, course
- [Lexcube: 3D Data Cube Visualization in Jupyter](https://github.com/msoechting/lexcube): Python tool to explore 3D arrays (NumPy, xarray) as interactive cubes in Jupyter, with zoom, colormaps and time series plots. See [[Data]]. *Keywords*: data cube, visualization, Jupyter, xarray, 3D
- [#PythonDatavizChallenge (Spatial Thoughts)](https://spatialthoughts.com/2024/10/13/pythondatavizchallenge/): Free 30-day video course on making charts, maps, animations and dashboards in Python with Matplotlib, XArray, Folium, Leafmap, Lonboard and Streamlit. See [[Cartography]]. *Keywords*: data visualization, mapping, Python, Streamlit, Leafmap
- [DSSATTools](https://py-dssattools.readthedocs.io/en/latest/DSSATTools.html#DSSATTools.Crop): Python library for scripting DSSAT crop simulations, with classes for experiment (FileX), weather and soil files. Main topic: [[Agriculture]]. *Keywords*: DSSAT, crop model, Python, simulation, crop yield
- [LISS4 Image Processing using XArray and Dask (Spatial Thoughts)](https://spatialthoughts.com/2023/12/25/liss4-processing-xarray/): Tutorial: download ISRO LISS-4 imagery from Bhoonidhi and use XArray, rioxarray and Dask to convert it to TOA reflectance as a Cloud-Optimized GeoTIFF. Main topic: [[Remote_Sensing]]. *Keywords*: LISS-4, ISRO, XArray, Dask, reflectance, COG
- [AIforGood 2025 - segment-geospatial workshop](https://samgeo.gishub.org/workshops/AIforGood_2025/): Hands-on workshop on segmenting satellite and aerial imagery with SAMGeo (Segment Anything): point/box/text prompts, time series and cleaning outputs. Main topic: [[Remote_Sensing]]. See also [[Deep_Learning]]. *Keywords*: SAMGeo, Segment Anything, segmentation, workshop, building footprints
- [Cloud Native Remote Sensing with Python (Spatial Thoughts, August 2026)](https://spatialthoughts.com/training/python_remote_sensing_20260804/): Spatial Thoughts training page for its August 2026 class on cloud-native remote sensing with Python (materials behind a passphrase). Main topic: [[Remote_Sensing]]. *Keywords*: cloud-native, remote sensing, Python, training, Spatial Thoughts
- [NISAR Polarimetric Analysis Training Toolkit](https://github.com/dharmendraisro/nisar-polarimetric-training): Python/Jupyter training for NISAR L2 GCOV radar data: finding, subsetting, QC, visualization, GIS export and polarimetric decomposition. Main topic: [[Remote_Sensing]]. *Keywords*: NISAR, SAR, polarimetry, Jupyter, radar
- [Agribound](https://github.com/montimaj/agribound): Open-source Python toolkit that delineates agricultural field boundaries from satellite/aerial imagery (Landsat, Sentinel-2, HLS, NAIP) and embeddings (Google Satellite Embedding, TESSERA). Supports engines like Delineate-Anything, Fields of The World, Prithvi and DINOv3, with SAM 2 refinement. Main topic: [[Agriculture]]. See also [[Remote_Sensing]]. *Keywords*: field boundaries, delineation, satellite imagery, SAM, segmentation
