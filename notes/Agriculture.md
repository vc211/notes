# Agriculture

**Summary**: Notes on agriculture, including field mapping and crop monitoring from imagery.
**Last updated**: 2026-11-18

---

- [Course: QGIS for Precision Agriculture (OCWGIS)](https://courses.gisopencourseware.org/course/view.php?id=56): Free course on using QGIS for precision farming: open data, zonal statistics, field data collection with Mergin Maps and drone image processing with WebODM. See [[GIS]], [[Remote_Sensing]]. *Keywords*: QGIS, precision agriculture, drones, WebODM, course
- [The FutureCrop Challenge (Kaggle)](https://www.kaggle.com/competitions/the-future-crop-challenge/): Kaggle competition on predicting crop yields under future climate conditions with machine learning. See [[Machine_Learning]], [[Climate_Change]]. *Keywords*: crop yield, climate change, Kaggle, competition, prediction
- [How to access in-situ reference data via the WorldCereal RDM](https://esa-worldcereal.org/en/how-access-situ-reference-data-worldcereal-rdm): Guide to ESA WorldCereal's Reference Data Module for finding and downloading harmonized ground-truth land cover and crop type data, including through its API. See [[Data]], [[Remote_Sensing]]. *Keywords*: WorldCereal, reference data, crop type, ground truth, ESA
- [Spatialization of Crop Growth Simulation Model Using Remote Sensing (Springer)](https://link.springer.com/chapter/10.1007/978-981-15-6864-0_4): Book chapter on running crop growth simulation models over space by feeding them remote sensing data. See [[Remote_Sensing]]. *Keywords*: crop models, remote sensing, spatial simulation, yield, book chapter
- [DSSATTools](https://py-dssattools.readthedocs.io/en/latest/DSSATTools.html#DSSATTools.Crop): Python library for scripting DSSAT crop simulations, with classes for experiment (FileX), weather and soil files. See [[Python]]. *Keywords*: DSSAT, crop model, Python, simulation, crop yield
- [DSSAT data folder (dssat-csm-os)](https://github.com/DSSAT/dssat-csm-os/tree/develop/Data): Data folder of the open-source DSSAT crop model: genotype, pest, standard data and definition (.CDE) files. See [[Data]]. *Keywords*: DSSAT, crop model, genotype files, model data
- [dssat-docker](https://github.com/DSSAT/dssat-docker): Dockerfiles and instructions to build DSSAT in a Docker container and run it on local experiment or batch files. *Keywords*: DSSAT, Docker, crop model, containers
- [NDVI from First Principles (Streambatch)](https://www.streambatch.io/knowledge/ndvi-from-first-principles): Explainer that builds up NDVI from the basics of how plants reflect red and near-infrared light. Main topic: [[Remote_Sensing]]. *Keywords*: NDVI, vegetation index, reflectance, near-infrared
- [Beyond NDVI: What are vegetation indices, and how are they used in precision farming? (Geoawesomeness)](https://geoawesomeness.com/eo-hub/beyond-ndvi-what-are-vegetation-indices-and-how-are-they-used-in-precision-farming/): Article on vegetation indices other than NDVI and how they are used in precision farming. See [[Remote_Sensing]]. *Keywords*: vegetation indices, NDVI, precision farming, crop monitoring
- [URBAL Sustainable Food Guide](https://urbal-sustainablefood.guide/): Free step-by-step method to map how sustainable food system innovations create change, with barriers, enablers and indicators. See [[Urban_Planning]]. *Keywords*: food systems, sustainability, impact assessment, indicators, urban food
- [Planet Tanager open data: Agriculture (STAC)](https://www.planet.com/data/stac/browser/tanager-core-imagery/agriculture/collection.json): Planet open-data STAC collection of Tanager hyperspectral imagery over agricultural areas. Main topic: [[Remote_Sensing]]. *Keywords*: hyperspectral, Tanager, Planet, STAC, open data
- [How Well Do Crop-Type Models Transfer with Embeddings? Exploring Generalization with AlphaEarth Embeddings](https://esmaeeladrah.com/2025/09/14/generalizing-crop-types-with-embedding/): Tests Random Forest crop classifiers on AlphaEarth embeddings across US, France and years; they transfer well, except wheat and barley across countries. See [[Embeddings]], [[Machine_Learning]]. *Keywords*: AlphaEarth, crop type, transfer learning, Random Forest, embeddings
- [Global Fields of The World (FTW) dataset (Source Cooperative)](https://source.coop/ftw/global-data): Global 10 m farm field boundaries: about 1.6 billion polygons per year for 2024-2025 in 195 countries, as GeoParquet, PMTiles and Zarr (CC-BY-4.0). See [[Data]], [[Remote_Sensing]]. *Keywords*: field boundaries, global dataset, GeoParquet, Sentinel-2, Fields of The World
- [crop-stage-detection (NASA Harvest)](https://github.com/nasaharvest/crop-stage-detection): Crop-agnostic model that estimates a field's growth stage from an NDVI time series (Sentinel-2/Landsat via Earth Engine), no crop calibration needed. See [[Remote_Sensing]]. *Keywords*: crop phenology, growth stage, NDVI, NASA Harvest, time series
- [crop-cycle-detection (NASA Harvest)](https://github.com/nasaharvest/crop-cycle-detection): Crop-agnostic model that finds each cropping cycle in an NDVI time series and extracts green-up, peak, start and end of season. See [[Remote_Sensing]]. *Keywords*: cropping cycles, phenology, NDVI, NASA Harvest, seasons
- [Agribound](https://github.com/montimaj/agribound): Open-source Python toolkit that delineates agricultural field boundaries from satellite/aerial imagery (Landsat, Sentinel-2, HLS, NAIP) and embeddings (Google Satellite Embedding, TESSERA). Supports engines like Delineate-Anything, Fields of The World, Prithvi and DINOv3, with SAM 2 refinement. See [[Python]], [[Remote_Sensing]]. *Keywords*: field boundaries, delineation, satellite imagery, SAM, segmentation
