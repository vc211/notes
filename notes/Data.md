# Data

**Summary**: Notes on datasets, data formats and data standards. Related: [[Remote_Sensing]], [[Climate_Change]].
**Last updated**: 2026-11-18

---

- [PostGIS spatial joins in DuckDB (Geomermaids)](https://www.geomermaids.com/cookbook/duckdb-spatial/): Rewrites common PostGIS spatial joins for DuckDB and compares query plans on FEMA flood data. Tips: explicit R-tree indexes, one spatial predicate per join, metric CRS for distance joins, inlined bounding boxes to clip Parquet. Main topic: [[SQL]]. See also [[GIS]]. *Keywords*: DuckDB, spatial SQL, spatial joins, query optimization, R-tree, PostGIS
- [Global bare soil, photosynthetic and non-photosynthetic vegetation fraction, annual at 500 m](https://zenodo.org/records/12071317): Zenodo dataset of yearly global maps at 500 m showing the share of bare soil, green vegetation and dry (non-photosynthetic) vegetation per pixel. Main topic: [[Soil]]. See also [[Remote_Sensing]]. *Keywords*: fractional cover, bare soil, vegetation, global dataset, MODIS
- [Historical time-series reconstruction benchmark dataset of Landsat bi-monthly aggregates](https://zenodo.org/records/11150343): Zenodo benchmark dataset of Landsat bi-monthly composites for testing methods that fill gaps and rebuild historical image time series. Main topic: [[Remote_Sensing]]. See also [[Machine_Learning]]. *Keywords*: Landsat, gap filling, time series, benchmark, reconstruction
- [How to access in-situ reference data via the WorldCereal RDM](https://esa-worldcereal.org/en/how-access-situ-reference-data-worldcereal-rdm): Guide to ESA WorldCereal's Reference Data Module for finding and downloading harmonized ground-truth land cover and crop type data, including through its API. Main topic: [[Agriculture]]. See also [[Remote_Sensing]]. *Keywords*: WorldCereal, reference data, crop type, ground truth, ESA
- [Lexcube: 3D Data Cube Visualization in Jupyter](https://github.com/msoechting/lexcube): Python tool to explore 3D arrays (NumPy, xarray) as interactive cubes in Jupyter, with zoom, colormaps and time series plots. Main topic: [[Python]]. *Keywords*: data cube, visualization, Jupyter, xarray, 3D
- [DSSAT data folder (dssat-csm-os)](https://github.com/DSSAT/dssat-csm-os/tree/develop/Data): Data folder of the open-source DSSAT crop model: genotype, pest, standard data and definition (.CDE) files. Main topic: [[Agriculture]]. *Keywords*: DSSAT, crop model, genotype files, model data
- [Overture Maps Foundation releases its first world-wide open map dataset](https://overturemaps.org/overture-maps-foundation-releases-first-world-wide-open-map-dataset/): Announcement of Overture Maps' first global open map data release (places, buildings, transport, admin boundaries). Main topic: [[Cartography]]. *Keywords*: Overture Maps, open map data, buildings, places, basemap
- [Soil Spectroscopy for Global Good (GitHub)](https://github.com/soilspectroscopy): GitHub organization for the Open Soil Spectral Library (OSSL): data, calibration models, chemometrics tools and training on predicting soil properties from spectra. Main topic: [[Soil]]. See also [[Machine_Learning]]. *Keywords*: soil spectroscopy, OSSL, chemometrics, spectral library, soil properties
- [APIs | Copernicus Data Space Ecosystem](https://dataspace.copernicus.eu/analyse/apis): Overview of Copernicus APIs: catalogues (OData, STAC), openEO and Sentinel Hub for processing, OGC map services and on-demand processing. Main topic: [[Remote_Sensing]]. *Keywords*: Copernicus, Sentinel, STAC, openEO, Sentinel Hub, API
- [An open-access database of nature-based carbon offset project boundaries (Research Square)](https://www.researchsquare.com/article/rs-4535931/v1): Preprint presenting an open database of the mapped boundaries of nature-based carbon offset projects. Main topic: [[Carbon_Markets]]. See also [[Forests]]. *Keywords*: carbon offsets, project boundaries, nature-based solutions, open data
- [Natural Earth: Downloads](https://www.naturalearthdata.com/downloads/): Free public-domain vector and raster map data at 1:10m, 1:50m and 1:110m scales, in SHP, SQLite or GeoPackage. Main topic: [[Cartography]]. *Keywords*: Natural Earth, basemap, vector data, boundaries, free data
- [Second Administrative Level Boundaries (UN SALB)](https://salb.un.org/en/data?title=&field_un_region_target_id=All): UN programme providing country-validated second-level administrative boundary data (e.g. districts), by country. Main topic: [[Cartography]]. *Keywords*: administrative boundaries, UN, SALB, districts, open data
- [OpenLandMap Soil Platform (OpenGeoHub)](https://world.soils.app/olm-soildb/): OpenGeoHub platform to explore and access open soil data (SoilDB). Main topic: [[Soil]]. *Keywords*: soil data, OpenLandMap, OpenGeoHub, soil database
- [Global Fields of The World (FTW) dataset (Source Cooperative)](https://source.coop/ftw/global-data): Global 10 m farm field boundaries: about 1.6 billion polygons per year for 2024-2025 in 195 countries, as GeoParquet, PMTiles and Zarr (CC-BY-4.0). Main topic: [[Agriculture]]. See also [[Remote_Sensing]]. *Keywords*: field boundaries, global dataset, GeoParquet, Sentinel-2, Fields of The World
- [Cloud-Optimized Geospatial Formats Guide](https://guide.cloudnativegeo.org/): Guide to cloud-optimized geospatial formats (COG, Zarr, cloud HDF/NetCDF, COPC, GeoParquet, FlatGeobuf, PMTiles) and how to make and test them. See [[Remote_Sensing]]. *Keywords*: cloud-native, COG, Zarr, GeoParquet, PMTiles, formats
- [Groundsource: A Dataset of Flood Events from News](https://zenodo.org/records/18647054): Dataset of about 2.6 million historical flood events extracted from news articles across 150+ countries, published as one Parquet file (CC BY 4.0). Main topic: [[Climate_Change]]. *Keywords*: floods, natural hazards, dataset, news, Parquet
- [The Technical Debt of Earth Embedding Products](https://cloudnativegeo.org/blog/2026/02/the-technical-debt-of-earth-embedding-products/): Isaac Corley (Wherobots, Feb 2026) compares Earth embedding products (Clay, AlphaEarth, Tessera, Major TOM, Presto, Copernicus-Embed, Earth Index) by resolution, dimensions, license and storage cost. Argues they need shared standards: cloud-native formats, CRS metadata, provenance, benchmarks and quantization. Main topic: [[Remote_Sensing]]. See also [[Embeddings]]. *Keywords*: earth embeddings, geospatial foundation models, GeoParquet, cloud-native, interoperability
