# Machine Learning

**Summary**: Notes on machine learning methods, competitions and applications. Related: [[Agriculture]], [[Remote_Sensing]].
**Last updated**: 2026-11-18

---

- [The FutureCrop Challenge (Kaggle)](https://www.kaggle.com/competitions/the-future-crop-challenge/): Kaggle competition on predicting crop yields under future climate conditions with machine learning. Main topic: [[Agriculture]]. See also [[Climate_Change]]. *Keywords*: crop yield, climate change, Kaggle, competition, prediction
- [Historical time-series reconstruction benchmark dataset of Landsat bi-monthly aggregates](https://zenodo.org/records/11150343): Zenodo benchmark dataset of Landsat bi-monthly composites for testing methods that fill gaps and rebuild historical image time series. Main topic: [[Remote_Sensing]]. See also [[Data]]. *Keywords*: Landsat, gap filling, time series, benchmark, reconstruction
- [AI Python for Beginners (DeepLearning.AI)](https://learn.deeplearning.ai/courses/ai-python-for-beginners/lesson/2/what-is-computer-programming%3F): Beginner course teaching Python basics (data, variables, functions) while writing code alongside an AI chatbot. Main topic: [[Python]]. *Keywords*: Python, beginners, AI assistant, course, programming basics
- [Soil Spectroscopy for Global Good (GitHub)](https://github.com/soilspectroscopy): GitHub organization for the Open Soil Spectral Library (OSSL): data, calibration models, chemometrics tools and training on predicting soil properties from spectra. Main topic: [[Soil]]. See also [[Data]]. *Keywords*: soil spectroscopy, OSSL, chemometrics, spectral library, soil properties
- [How Well Do Crop-Type Models Transfer with Embeddings? Exploring Generalization with AlphaEarth Embeddings](https://esmaeeladrah.com/2025/09/14/generalizing-crop-types-with-embedding/): Tests Random Forest crop classifiers on AlphaEarth embeddings across US, France and years; they transfer well, except wheat and barley across countries. Main topic: [[Agriculture]]. See also [[Embeddings]]. *Keywords*: AlphaEarth, crop type, transfer learning, Random Forest, embeddings
