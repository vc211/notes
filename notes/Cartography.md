# Cartography

**Summary**: Notes on map making and basemap data such as boundaries. Related: [[GIS]], [[Data]].
**Last updated**: 2026-11-18

---

- [Creating a Block World Map (QGIS3)](https://www.qgistutorials.com/en/docs/3/block_world_styling.html): QGIS tutorial that turns a hex grid of elevation data into a 2.5D block map using expressions and color ramps, with DEM data from OpenTopography. See [[GIS]]. *Keywords*: QGIS, 2.5D map, hex grid, elevation, map styling
- [#PythonDatavizChallenge (Spatial Thoughts)](https://spatialthoughts.com/2024/10/13/pythondatavizchallenge/): Free 30-day video course on making charts, maps, animations and dashboards in Python with Matplotlib, XArray, Folium, Leafmap, Lonboard and Streamlit. Main topic: [[Python]]. *Keywords*: data visualization, mapping, Python, Streamlit, Leafmap
- [Overture Maps Foundation releases its first world-wide open map dataset](https://overturemaps.org/overture-maps-foundation-releases-first-world-wide-open-map-dataset/): Announcement of Overture Maps' first global open map data release (places, buildings, transport, admin boundaries). See [[Data]]. *Keywords*: Overture Maps, open map data, buildings, places, basemap
- [Natural Earth: Downloads](https://www.naturalearthdata.com/downloads/): Free public-domain vector and raster map data at 1:10m, 1:50m and 1:110m scales, in SHP, SQLite or GeoPackage. See [[Data]]. *Keywords*: Natural Earth, basemap, vector data, boundaries, free data
- [Second Administrative Level Boundaries (UN SALB)](https://salb.un.org/en/data?title=&field_un_region_target_id=All): UN programme providing country-validated second-level administrative boundary data (e.g. districts), by country. See [[Data]]. *Keywords*: administrative boundaries, UN, SALB, districts, open data
